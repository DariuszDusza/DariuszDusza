from Linux systems administration to engineering lead, and for the last two years mostly working

observability problem more than a prompting problem. That is the part I like to build.

**What I work on**

- **Platform and reliability:** Terraform on Google Cloud, CI/CD, observability, incident response
- **Applied AI:** retrieval-augmented generation, self-hosted models, evals before trust

**Featured**

[**agentic-dev-harness**](https://github.com/DariuszDusza/agentic-dev-harness): a vendor-neutral
harness for running coding agents on a real codebase. Guidance and guardrails, reviewer and

their own test suite, and retrieval evals.

**How I like to build**

- A run that did nothing must never read as a run that found nothing.
