- **Platform and reliability:** Terraform on Google Cloud, CI/CD, observability, incident response

**Featured**

[**agentic-workflow-foundry**](https://github.com/DariuszDusza/agentic-workflow-foundry): a
vendor-neutral agentic workflow that lets AI coding agents work safely on real codebases.
On-demand guardrails, 14 reviewer and workflow agents, 16 self-tested gates, an in-repo backlog
with declared merge gates, and a contract-bound reference API and UI.

It grew out of [agentic-dev-harness](https://github.com/DariuszDusza/agentic-dev-harness), the
earlier version.

**How I like to build**

- The safe way should be the easy way.
- Nothing lands without review, and no agent approves its own work.
- A run that did nothing must never read as a run that found nothing.
